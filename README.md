# プリビズ設計スタジオ（PREVIS STUDIO）

スマートフォンで自由にプリビズを設計する、GitHub Pages用の静的Webアプリです。ログイン不要・サーバー不要。ビルドも不要です。

## できること

- 舞台選択：急坂と海／平地／街／海／何もない空間
- 人物（球の頭＋柱の胴体）／箱／球／柱／円すい／リングを好きな数だけ追加、複製、削除
- 選んだ物体の位置 X・Y・Z、色、大きさを変更
- 編集視点で画面をスワイプして視点を回転・ピンチでズーム
- 「物体を動かす」モードで、画面内の物体を指でドラッグして位置を変更
- 動く物体の位置を秒ごとに登録し、ポイント間の移動を再生。上から見たルート図のポイントもドラッグ可能
- 顔アップ／横顔／真上／背中／肩越し／ドローン／自由視点のカメラを時間別に登録。撮影対象も選択可能
- カメラ切替時間は0～2秒で調整（初期値0.4秒）
- 動画の尺 10／15／30／45／60／90／120秒、比率 縦9:16／横16:9／正方形
- 複数作品の自動保存・複製・切替、JSONバックアップと再読込
- AI動画用のショット指示をTXT保存・コピー
- 対応ブラウザでは無音のMP4/WebM録画。直接出力不可のSafari向けにはiPhone画面収録モード
- GitHub PagesからSafariで開いてホーム画面に追加

## iPhoneだけで公開する最も簡単な方法（HTML 1ファイル）

**まずは別途同梱した「簡単版」の `index.html` 1個で始めることを推奨します。**

1. Safariで https://github.com/new を開き、GitHubにログイン
2. `Repository name` に `previs-studio` と入力。`Public` を選択し「Create repository」
3. リポジトリで `Add file` → `Upload files` を選択。「簡単版」の `index.html` 1個をアップロードし、「Commit changes」を押す
4. `Settings` → `Pages` → `Build and deployment` → `Deploy from a branch` → `main` → `/(root)` → `Save`
5. 数分後、 `https://ユーザー名.github.io/previs-studio/` にアクセス
6. Safariの共有ボタンから「ホーム画面に追加」。表示されたら「Webアプリとして開く」をオンにして追加

`Add file` が見えない場合、Safariで「デスクトップ用Webサイトを表示」に切り替えてください。

### 完全PWA版（こちらのフォルダ全部）

こちらはサービスワーカー・アイコン・キャッシュを含みます。ZIPの中の**ファイルとフォルダを展開してからリポジトリ直下に配置**してください。ZIPを1個そのまま置いても、サイトにはなりません。

```
index.html
app.js
style.css
manifest.webmanifest
sw.js
.nojekyll
icons/
  apple-touch-icon.png
  icon-192.png
  icon-512.png
README.md
```

公開設定とホーム画面への追加は簡単版と同じです。PWAは一度オンラインで読み込むとアプリ本体がオフラインキャッシュされます。Three.jsはCDN経由なので、オフラインや読み込めない場合は内蔵のCanvas 3Dに自動切替します。

## 操作の流れ

1. 「舞台」で地形・長さ・画角を指定
2. 「物体」で追加して座標・色・大きさを変更
3. 「動き」でタイムラインを合わせ、位置を指定し「この秒数に動きを記録」
4. 「カメラ」でターゲットとショットを選び、必要な秒数にキーを登録
5. ▶ で全体確認。「保存」から動画やAI用ショット指示を書き出す

### 制限と注意

- アップした写真から人物の顔を自動3Dモデル化する機能はありません。人物は抽象化した球＋柱です。
- 本体はプリビズ（事前構成）の設計用です。フォトリアルな完成動画の生成機能はありません。
- このアプリはiPhoneのSafari実機での動作検証を完了していません。書き出し形式はブラウザ機能によって異なります。
- 保存した作品はその端末・その公開URLのブラウザ内（localStorage）に保存されます。機種変更やSafariデータ削除に備えてJSONバックアップしてください。GitHubに作品データが自動アップロードされることはありません。
- GitHub Pagesに配置したプログラムファイルは公開されます。個人情報や非公開資料を埋め込まないでください。
